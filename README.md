# Thiranex Internship — Task 2
## Advanced CSS3 & Responsive Architecture

Built directly on Task 1 without removing its semantic HTML5 or accessibility features.

### Task 2 additions
- Mobile-first responsive CSS
- CSS Grid for page/card layouts
- Flexbox for navigation, controls and footer
- CSS custom properties in `:root`
- Light/dark theme with accessible keyboard toggle
- `clamp()`, `min()`, `max()`, `calc()`
- `aspect-ratio`, gradients, shadows, transforms and transitions
- Responsive breakpoints for tablet and desktop
- Reduced-motion support
- Overflow-safe responsive sizing
- Responsive project/skill cards and form controls

### Task 1 preserved
Semantic landmarks, skip link, heading hierarchy, accessible labels, ARIA validation/status messages, keyboard navigation, visible focus states and SEO metadata.

### Explicitly excluded
No backend, database, authentication, login/signup, Python, Django, Flask, IPL/cricket, admin dashboard or payment functionality.

### Test before submission
Check all 5 pages at mobile, tablet and desktop widths. Run Lighthouse Accessibility and SEO on every page. Test Tab/Shift+Tab/Enter, skip link, mobile menu, theme toggle, form validation, zoom and dark-mode contrast.
